# Nano Oscilloscope

A simple, portable oscilloscope project built using an Arduino Nano and an SSD1306 128x64 I2C OLED display.

![Oscilloscope in action](demo.gif)

## Introduction
The Nano Oscilloscope is a lightweight, DIY tool designed to visualize analog signals. It leverages the Arduino Nano's analog-to-digital converter (ADC) and high-speed I2C communication to capture and display waveforms on a small OLED screen. It includes a built-in test signal generator, making it easy to start exploring right away.

## Features
*   **Real-time Waveform Display:** Visualizes signals on a 128x64 I2C OLED screen.
*   **Variable Sampling Rate:** Adjust the sampling speed using an external potentiometer.
*   **Pause Mode:** Easily freeze the waveform for closer inspection by turning the potentiometer fully down.
*   **Built-in Test Signal:** Generates a ~490Hz square wave on Pin 3, allowing you to test the oscilloscope immediately without an external signal source.
*   **Status Indicators:** Displays "RUN" or "PAUSED" mode and the current sampling delay.

## Pinout
The following pin configuration is used on the Arduino Nano:

| Pin | Function | Description |
| :--- | :--- | :--- |
| **A0** | `SIGNAL_PIN` | Analog signal input probe. |
| **A1** | `POT_PIN` | Potentiometer input for controlling sampling rate/pause. |
| **D9** | `LED_PIN` | PWM-capable pin for status LED (dim glow when paused). |
| **D3** | `TEST_PIN` | Built-in square wave test signal output. |
| **A4** | `SDA` | I2C Data pin for the OLED display. |
| **A5** | `SCL` | I2C Clock pin for the OLED display. |

*Note: Connect the SSD1306 OLED's VCC and GND to the Nano's 5V and GND respectively.*

## Bill of Materials (BOM)
To build this project, you will need:

1.  **Arduino Nano** (or compatible ATmega328P based board)
2.  **SSD1306 128x64 I2C OLED Display**
3.  **10kΩ Potentiometer** (for sampling control)
4.  **LED** (optional, for status indication)
5.  **Current-limiting Resistor** (e.g., 220Ω - 330Ω, for the LED)
6.  **Breadboard and Jumper Wires**

## How to Test
1.  Upload the `code.ino` sketch to your Arduino Nano.
2.  Connect the SSD1306 display to the I2C pins (A4/SDA, A5/SCL).
3.  For a quick test, connect a jumper wire from **Digital Pin 3** to **Analog Pin A0**.
4.  The OLED should display the square wave generated by the test signal.
5.  Adjust the potentiometer to change the sampling speed or set it to zero to pause the display.
